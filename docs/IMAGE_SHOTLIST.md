# IMAGE SHOTLIST — S South Coorg Security Services (SSCSS)

> **Exhaustive per-page, per-section creative brief.** For every section across every page this file answers:
> 1. Does the section need an image? (YES / NO)
> 2. Why? (trust / emotion / clarity / storytelling / conversion / credibility)
> 3. Exactly what image should be there (specific shot description).
> 4. Style (Corporate / Premium / Documentary / Editorial / Lifestyle / Cinematic / Natural / Drone / Wide / Portrait / Close-up).
> 5. Orientation (Landscape / Portrait / Square / 16:9 / 4:5 / 3:2).
> 6. Priority (Critical / High / Medium / Low).
> 7. Production method (Real photography / illustration / 3D render / icon only / background texture / SVG).
> 8. Reuse locations.
> 9. **Preferred Media (Photo / Video / Either)** + Reason.
> 10. **Photography prompt / creative brief** (usable directly with a photographer or as an AI concept prompt).
