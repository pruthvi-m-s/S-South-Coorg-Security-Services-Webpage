# SSCSS Website — Handoff Guide

## Quick Start

```bash
npm install
npm run dev        # Local dev server at http://localhost:5173
npm run build      # Production build → dist/
npm run preview    # Preview production build locally
npm run lint       # Run ESLint
```

## Deployment (Vercel)

### First-time setup
1. Install Vercel CLI: `npm i -g vercel`
2. Login: `vercel login`
3. Link project: `vercel` (follow prompts)

### Deploy
- **Preview:** Push to any branch → Vercel auto-deploys a preview URL
- **Production:** `vercel --prod` or merge to `main` (if GitHub integration is set up)

### Vercel Project Settings
- **Framework:** Vite
- **Build command:** `npm run build`
- **Output directory:** `dist`
- **Install command:** `npm install`

## Content Updates

All business content lives in `src/content/`. **No code changes needed** for text updates.

### Key content files
- `src/content/site.ts` — Company info, contact details, NAP data
- `src/content/home.ts` — Homepage copy (hero, pain points, proof, services preview)
- `src/content/services.ts` — All 14 service definitions
- `src/content/services-hub.ts` — Services page grouping (4 buyer groups)
- `src/content/about.ts` — About page content
- `src/content/clients-page.ts` — Client logos and industries
- `src/content/contact-page.ts` — Contact page copy and form config
- `src/content/faq.ts` — FAQ entries
- `src/content/stats.ts` — Statistics numbers
- `src/content/testimonials.ts` — Client testimonials
- `src/content/hero.ts` — Homepage hero content
- `src/content/founder.ts` — Founder bio

### Editing a service
1. Open `src/content/services.ts`
2. Find the service object
3. Edit `name`, `description`, `shortDescription`, `features`, `idealFor`, etc.
4. Run `npm run build` to verify

### Adding a new service
1. Add entry to `src/content/services.ts`
2. Add slug to `src/lib/routes.ts` serviceRoutes
3. Add to `src/content/services-hub.ts` group
4. Add content block to `src/content/services/[slug].ts`
5. Add responsive images to `public/images/site/` and `public/images/responsive/site/`
6. Run build — prerender will automatically include the new route

### Updating images
1. Place source images in `public/images/site/` (kebab-case, `.webp`)
2. Create responsive variants: `public/images/responsive/site/[name]-{480,768,1024,1400}.webp`
3. Image paths are auto-generated by `ImageWithSkeleton` component from source filename

### Image naming convention
```
public/images/site/entrance-office-guards.webp              (original)
public/images/responsive/site/entrance-office-guards-480.webp   (480px)
public/images/responsive/site/entrance-office-guards-768.webp   (768px)
public/images/responsive/site/entrance-office-guards-1024.webp  (1024px)
public/images/responsive/site/entrance-office-guards-1400.webp  (1400px)
```

## Architecture

### Tech Stack
- **Vite 8** — Build tool
- **React 19** — UI framework
- **TypeScript 6** — Type safety
- **Tailwind CSS 4** — Styling
- **React Router 7** — Client-side routing
- **Framer Motion** — Animations
- **shadcn/ui** — Component primitives

### Project Structure
```
src/
├── components/
│   ├── common/          Shared components (ImageWithSkeleton, AnimatedCounter, etc.)
│   ├── forms/           Contact form
│   ├── layout/          Header, Footer, Layout
│   ├── navigation/      Navigation components
│   ├── sections/        Page sections (Hero, ProcessTimeline, etc.)
│   └── ui/              shadcn primitives
├── content/             All business copy (single source of truth)
├── lib/                 Utilities, analytics, SEO, routes, structured data
├── pages/               Route-level page components
└── types/               TypeScript interfaces
```

### SEO
- Static prerendering via Playwright (`scripts/prerender.mjs`) — 23 routes
- JSON-LD structured data (LocalBusiness, Service, FAQPage schemas)
- Auto-generated `sitemap.xml`, `robots.txt`, `llms.txt` from `VITE_SITE_URL`
- OpenGraph + Twitter meta tags on every page

### Forms
- Contact form → `api/contact.js` (Vercel serverless) → Google Apps Script
- To update the Google Apps Script endpoint, update the env var `VITE_CONTACT_FORM_ENDPOINT`
- Or edit `api/contact.js` directly

### Analytics
- GA4 integration via `src/lib/analytics/`
- Custom event tracking (CTA clicks, form submissions, service page views)
- Requires `VITE_GA4_MEASUREMENT_ID` env var

## Troubleshooting

### Build fails with "VITE_SITE_URL is required"
Set `VITE_SITE_URL` in `.env` or Vercel dashboard before building.

### Images show 404
Ensure responsive image files follow the naming convention:
- Source: `public/images/site/kebab-case-name.webp`
- Variants: `public/images/responsive/site/kebab-case-name-{480,768,1024,1400}.webp`

### Form submission fails
1. Check `api/contact.js` is deployed (Vercel serverless)
2. Verify Google Apps Script URL is correct
3. Check browser console for CORS errors

### Prerender fails
Run `npx playwright install chromium` to ensure Playwright browser is available.
